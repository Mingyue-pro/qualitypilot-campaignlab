# CampaignLab 变更记录

## V1.0（开发中）

- 确认改为受 MDP 经验启发的合成营销流程平台。
- 定义客群、审批、状态、过滤、互斥、频控、对照组、模拟渠道和监控基线。
- 旧的“活动库存与权益领取”代码仅为早期技术骨架，正在被本基线替代。

## V1.1（需求已确认，尚未实现）

- 首个新需求收敛为“单计划用户日触达频控”，需求包位于 `requirements/v1.1/`。
- 统计维度固定为计划、用户和 `Asia/Shanghai` 自然日，跨该计划当天全部执行批次。
- 成功和失败渠道调用均计数；频控拦截不调用渠道，只记录 `FREQUENCY_CAPPED` 节点轨迹。
- 多层时间窗口、跨计划全局频控、互斥优先级和真实渠道继续延期。
- 当前仅完成需求基线，Java、Vue、Flyway与OpenAPI均尚未实现V1.1。
